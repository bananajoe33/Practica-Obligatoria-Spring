# Requisitos Funcionales

El sistema de gestión de instituto contará con las siguientes funcionalidades, centradas en las entidades **Alumno** y **Grupo**.

## 1. Gestión de Alumnos
- **RF1**: Crear un alumno con nombre, apellidos, correo y fecha de nacimiento.  
- **RF2**: Modificar los datos de un alumno existente.  
- **RF3**: Eliminar un alumno.  
- **RF4**: Consultar la lista de alumnos registrados.

## 2. Gestión de Grupos
- **RF5**: Crear un grupo con nombre y código único.  
- **RF6**: Modificar los datos de un grupo.  
- **RF7**: Eliminar un grupo.  
- **RF8**: Consultar la lista de grupos registrados.
