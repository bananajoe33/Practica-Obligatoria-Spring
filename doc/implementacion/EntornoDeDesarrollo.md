# Entornos de Desarrollo

## Entorno Local
- **IDE:** VS Code
- **JDK:** Java 17
- **Spring Boot:** Versión 3.5.7
- **Base de Datos:** H2 en memoria para desarrollo y pruebas
- **Contenedores:** Dev Container configurado para la ejecución del proyecto
- **Control de Versiones:** Git

## Gestión de Versiones
- **Flujo de trabajo:** Git Flow
- **Ramas principales:**
  - `develop`: rama de desarrollo
  - `feature/*`: ramas de nuevas funcionalidades
  - `release/*`: ramas de preparación de versión
  - `main` o `master`: rama de producción
