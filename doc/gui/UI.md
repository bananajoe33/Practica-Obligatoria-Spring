## Interfaz de Usuario (UI)

La interfaz de usuario del proyecto está desarrollada utilizando **Thymeleaf** como motor de plantillas.  
Todas las vistas HTML se encuentran en el directorio:


Las principales vistas utilizadas en la aplicación son:

- **home.html** → Página principal de navegación.
- **alumnos-lista.html** → Vista donde se muestra el listado completo de alumnos.
- **alumnos-formulario.html** → Formulario para crear o editar un alumno.
- **alumno-creado.html** → Pantalla de confirmación tras crear un alumno correctamente.
