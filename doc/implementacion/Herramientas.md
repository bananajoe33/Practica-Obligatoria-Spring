## Herramientas
- **Git:** para control de versiones y flujo Git Flow
- **Docker / Dev Container:** para aislamiento del entorno de desarrollo
- **Postman:** para pruebas de APIs REST
- **H2 Console:** para gestión de la base de datos en memoria
- **Maven:** para construcción y gestión de dependencias del proyecto
- **Spring Boot Dashboard:** para arrancar y monitorizar la aplicación desde VS Code
- **JUnit 5:** para pruebas unitarias
- **Mockito:** para creación de mocks y simulación de dependencias en tests

## Gestión de Versiones
- **Flujo de trabajo:** Git Flow
- **Ramas principales:**
  - `develop`: rama de desarrollo
  - `feature/*`: ramas de nuevas funcionalidades
  - `release/*`: ramas de preparación de versión
  - `main` o `master`: rama de producción
